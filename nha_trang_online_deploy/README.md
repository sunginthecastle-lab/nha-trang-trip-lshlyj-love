# Nha Trang Trip 2026 — 온라인 배포용

로그인
- 아이디: 이예지
- 비밀번호: 멍청이

## 중요한 점
이 패키지는 온라인 호스팅에 올릴 수 있는 서버형 사이트입니다.
PC와 아이폰이 같은 온라인 서버에 접속하면 동일한 여행 데이터를 공유합니다.

### 배포
Node.js 18+가 지원되는 호스팅 서비스에 이 폴더를 업로드하고 Start Command를 `node server.js`로 설정하세요.

### 비밀번호 변경
서버 환경변수 `TRIP_PASSWORD`를 설정하면 기본 비밀번호 대신 그 값을 사용합니다.

### 현재 데이터 저장
`data.json` 파일에 저장됩니다. 호스팅 서비스에서 디스크가 영구 저장되는지 확인해야 합니다.
실서비스에서는 Supabase/PostgreSQL 같은 외부 DB로 바꾸는 것을 권장합니다.
